# 요트 게임 · ruleset yacht-v1

2–4인, 5개 주사위, 12라운드. 시작 시 서버가 좌석 순서를 섞고 이후 고정한다. 각 플레이어는 카테고리마다 정확히 한 번 기록한다. 턴당 최대 3회 굴리고, 첫 굴림 뒤 점수를 기록할 수 있다. 보관은 인덱스 0–4에 적용하며 다음 굴림까지 유지한다. 전부 보관했으면 다시 굴릴 수 없다. 새 턴에는 주사위와 보관을 초기화한다.

| 키 | 이름 | 점수 |
|---|---|---|
| ones~sixes | 1~6 | 해당 눈의 합 |
| choice | 초이스 | 다섯 눈의 합 |
| fourKind | 포카드 | 같은 눈 4개 이상이면 다섯 눈의 합 |
| fullHouse | 풀하우스 | 정확히 3개+2개면 다섯 눈의 합 |
| smallStraight | 작은 스트레이트 | 서로 다른 연속 눈 4개 이상이면 15 |
| largeStraight | 큰 스트레이트 | 1–5 또는 2–6이면 30 |
| yacht | 요트 | 같은 눈 5개면 50 |

조건에 미달하면 0점으로 기록할 수 있다. 상단 소계 63점 이상이면 35점 보너스. 요트 추가 보너스나 조커 규칙은 이 버전의 범위 밖이다. 총점은 12칸 합계와 상단 보너스의 합이다. 동점은 공동 순위(예: 1,1,3). 비어 있는 칸은 null, 확정한 0은 0으로 저장한다.

서버는 턴 시작 시 방의 턴 제한시간(1/2/3/4/5분, 기본 3분, 게임 시작 시 매치에 고정)으로 기한을 정한다. 기한 경과 시 굴림이 없었다면 1회 굴리고, 남은 칸 중 미리보기 점수 최대인 칸을 자동 확정한다. 동률은 표 순서. 재접속 중에도 기한은 흐른다. 두 요청이 경쟁하면 매치 행 잠금 아래 기한과 버전을 검증한다. 마지막 점수 확정과 결과 기록은 한 트랜잭션이다.

검증 예시: [2,2,2,3,3] 풀하우스 12, [6,6,6,6,6] 풀하우스 0·포카드 30·요트 50, [1,2,2,3,4] 작은 스트레이트 15·큰 스트레이트 0. 상단 62/63 경계, 중복 확정, 상대 턴, 4번째 굴림, 기한 경쟁, 전원 12칸 후 종료를 테스트한다.


## 구현 상태 (2026-11-09)

- 엔진: `packages/shared/engine.mjs`(순수 상태 전이, 난수 주입, 1–6인)와 `autoplay.mjs`(오토 전략). 서버·웹이 같은 코드를 쓴다. 테스트는 `node --test`(packages/shared).
- 서버: 매치 행 잠금 → 명령 영수증(commandId) → expectedVersion → 엔진 → 커밋 → 브로드캐스트. 게임 상태는 `matches.state`(JSONB)가 원본이고, 종료 시 `match_players.total/rank`를 기록한다.
- 시간 초과: 위 규칙(1회 굴림 + 최고점 칸, 동률은 표 순서). 같은 플레이어가 **연속 2회** 시간 초과하면 AWAY(서버 오토 진행)로 바뀌고, 직접 명령을 보내면 MANUAL로 복귀한다. 정책 값은 `game.policy.ts`에 있으며 확정 전 초안이다(Q3–Q5).
- 서버 재시작 시 진행 중 게임의 기한·오토 타이머를 DB에서 복구한다.


## 시작 안내 단계와 조작 UX (2026-11-09)

- **시작 안내(BRIEFING)**: PL이 시작하면 매치는 `phase=BRIEFING`이 된다. 이 동안 턴 기한이 없고(타이머 정지), 게임 명령은 `BRIEFING_IN_PROGRESS`로 거부되며 봇도 움직이지 않는다. 사람 참여자 모두가 `POST /matches/:id/briefing`(소켓 `match:briefed`)으로 확인하거나 건너뛰면 첫 턴 기한이 시작된다.
  - 봇은 자동 확인된다. 안내 중 퇴장한 사람은 확인 처리하고 AWAY로 바꾼다. 무응답이면 `BRIEFING_TIMEOUT_SEC`(기본 120초) 후 시작한다.
  - 화면의 "다시 보지 않기"는 브라우저 로컬 설정이다(`oy.guide.skip`). 켜 두면 안내를 띄우지 않고 바로 확인을 보낸다. 게임 중 [? 게임 방법]은 서버에 영향이 없다.
- **조작 흐름**: ① 표본 산출(주사위 굴리기) → ② 주사위를 눌러 표본 고정(보관)/해제, 재산출(고정 안 한 주사위만, 최대 3회) → ③ 점수표의 `+점수` 칸으로 **항목 선택**(계산 근거 표시, 기록 아님) → ④ **[항목 N점 확정]**으로 기록하고 턴을 끝낸다. 0점도 확정할 수 있다(경고 표시).
- 표시: 굴림 n/3, 다음 행동 안내, 분:초 타이머(30초 미만에서만 강조), 내 차례·기록 완료 알림, 항목명을 누르면 규칙 설명, 상단 소계 /63.
- 템포(UI 전용, 게임 기한과 무관): 봇·오토 플레이어의 턴 첫 동작 전 `AUTO_TURN_START_DELAY_MS`(1.8초), 이후 한 걸음 `AUTO_STEP_DELAY_MS`(1.1초), 굴림 애니메이션 0.8초. 애니메이션 축소 설정을 존중한다.
