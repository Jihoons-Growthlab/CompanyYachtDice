# 환경 설정 · UI 모드(Excel/CMD)

2026-11-09 구현. 개인 화면·연출 설정이며 본인 화면에만 적용된다. **방장의 턴 제한시간이나 서버의 봇 진행 속도와는 별개다.**

## 진입

모든 화면(접속·인사 등록·업무) 헤더 오른쪽 끝의 ⚙ 버튼(툴팁 "환경 설정")을 누르면 오른쪽 서랍이 열린다. 모바일에서는 하단 시트로 열린다. ESC·✕·⚙로 닫는다. 패널을 열고 닫아도 게임·소켓 상태는 바뀌지 않는다(`aria-modal=false`, 게임 화면을 막지 않음).

## 항목

| 그룹 | 항목 | 값 | 동작 |
|---|---|---|---|
| 화면 | UI 모드 | 엑셀(기본) / CMD | `html[data-ui-mode]`. 같은 컴포넌트에 테마 토큰만 교체. 새로고침 없이 즉시 바뀌고 게임 상태는 유지 |
| 화면 | UI 크기 | 작게(0.9) / 보통 / 크게(1.12) | `html[data-ui-scale]` → `body { zoom }` |
| 화면 | 애니메이션 축소 | ON/OFF | `html[data-reduced-motion=on]` → 모든 애니메이션·전환 제거. OS의 동작 줄이기 설정도 계속 존중 |
| 화면 | 게임 중 리본 접기 | ON/OFF | 게임 화면에서만 메뉴 탭·도구 모음 숨김 |
| 게임 연출 | 진행 연출 속도 | 빠르게 450ms / 보통 800ms / 느리게 1200ms | 주사위 애니메이션 시간(`--fx-dice-ms`)과 알림 표시 시간(2.0/3.2/4.8초) |
| 게임 연출 | 주사위 애니메이션 | ON/OFF | OFF면 결과만 즉시 표시 |
| 게임 연출 | 턴 시작 알림 | ON/OFF | "내 차례입니다" 토스트 |
| 사운드 | 효과음 / 음량 0–100% | 기본 OFF / 60% | Web Audio 합성음(파일·라이브러리 없음): 내 턴 시작·내 굴림·평가 확정·다른 사람 채팅. "미리 듣기" 버튼 |

## CMD 모드

엑셀 장식(리본·행/열 머리글·눈금)을 숨기고 터미널 창처럼 표시한다: 검정 배경, 고정폭 글꼴, 녹색·회색 텍스트. 상태줄 `[STATUS]`, 다음 행동 `C:\COMPANY> …`, 주사위 `[DICE]`, 굴리기 버튼 `C:\COMPANY> ROLL|REROLL`, 확정 버튼 `C:\COMPANY> CONFIRM ACES` 같은 형식이고, 채팅은 `[SYSTEM]`과 `<닉네임>` 로그로 보인다. 프롬프트 문구는 CSS(`::before`, `data-cmd`)로만 붙이므로 기능 로직과 버튼은 엑셀 모드와 같다. 명령어 직접 입력은 미구현이다(기존 수식 입력줄 `=ROLL()` 등은 그대로 동작).

대비: 본문 #d0d7de / 배경 #0c0c0c(약 13:1), 강조 #3fb950(약 8:1), 보조 #9aa4ae(약 7:1).

## 저장과 우선순위

- 로그인: 서버 `user_preferences`가 원본이다(GET/PATCH `/api/v1/me/preferences`, 본인만). 변경은 즉시 화면에 반영하고 300ms 동안 모아서 저장한다. 상태(저장 중·계정에 저장됨·저장 실패+다시 시도)를 표시한다. 같은 계정의 여러 브라우저는 마지막 저장이 우선이며, 다른 브라우저는 로그인·새로고침 때 반영된다(실시간 동기화 없음).
- 비로그인: localStorage `oy.prefs.guest`.
- 로그인 시: 서버에 저장된 설정이 있으면 **서버 우선**이다. 없으면(첫 로그인) 이 브라우저의 게스트 설정을 계정으로 올린다. 로그아웃하면 게스트 설정으로 돌아간다.
- 깜빡임 방지: `index.html` 인라인 스크립트가 `oy.prefs.applied`(모드·크기·애니메이션만, 계정 정보 없음)를 첫 렌더 전에 적용한다. 앱은 세션 확인 전에는 테마를 바꾸지 않는다.
