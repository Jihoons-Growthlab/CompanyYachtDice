# 채팅

MVP는 방 채팅. 방 멤버만 최근 메시지 50개와 이전 페이지를 읽거나 보낸다. 공백 제거 후 1–300 Unicode 코드 포인트를 받는다. 서버가 작성자·시간·방별 증가 순번을 지정한다. 텍스트로 렌더링하고 HTML은 해석하지 않는다. 사용자별 10초에 5건을 초과하면 RATE_LIMITED와 재시도 시간을 반환한다.

낙관적으로 보이는 메시지에는 전송 중 표시를 붙인다. ACK 손실 시 같은 clientMessageId로 재시도해 한 건만 저장한다. 연결 복구 시 마지막 순번 이후 페이지를 조회하고 ID로 합친다. MVP 보존 정책 초안은 30일이다. 신고·차단은 공개 배포 전에 설계한다. 비회원 구독, 스크립트 문자열, 중복 전송, 연결 중 누락을 검증한다.


## 구현 상태 (2026-11-09)

방 채팅을 구현했다(서버 `src/chat`, 화면 `RoomChat.vue`). 위 규칙(1–300자, 10초 5건, clientMessageId 중복 방지, 서버 지정 작성자·순번, 텍스트 렌더링, 30일 보관)을 따른다.
- 추가: 10줄 제한, 줄바꿈 외 제어문자와 방향 제어 문자 금지, 시스템 메시지(개설·입장·퇴장·준비·시작·종료·위임·초대·봇 제외), 작성 시점 닉네임·직급 스냅샷.
- 복원: room:subscribe ACK의 최근 50개, `GET /rooms/:id/messages?beforeSeq|afterSeq`. 소켓이 끊겨 있으면 화면이 REST로 전송하고, 실패하면 "다시 보내기"를 표시한다(같은 clientMessageId).
- 보관: 1시간마다 30일 지난 메시지를 삭제한다. 신고·차단은 미구현이다(공개 배포 전 설계).
