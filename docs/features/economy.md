# 코인·상점·인벤토리

성장 단계의 연결 계정에 적용한다. 가상 코인은 정수다. 출시 초안은 연결 시 120코인, 완주 20코인, 공동 1위 포함 1위 추가 10코인이다. 자동 확정이 한 번이라도 발생한 플레이어는 해당 경기 보상 대상에서 제외한다. 결과 확정 이후 매치·사용자별 단일 정산을 재시도할 수 있다. 상점은 비소모성 1개 한정 아이템만 제공한다. 예시 SKU plant-01 40코인, lamp-01 70코인.

구매 요청은 표시 당시 가격을 보낸다. 서버가 활성 SKU·현재 가격·소유·잔액을 다시 확인한다. 지갑 잠금 아래 주문, 음수 원장 항목, 잔액, 보유권을 함께 커밋한다. 같은 멱등 키와 같은 본문은 기존 성공 결과를 반환한다. 다른 본문이면 IDEMPOTENCY_CONFLICT. 가격 변경은 PRICE_CHANGED로 새 가격을 돌려준다.

검증: 잔액이 정확히 가격과 같을 때 성공, 동시 구매로 잔액 음수 방지, 중복 보상 방지, 이미 보유·비활성 SKU·가격 변경 시 무차감, 주문 실패 시 원장 롤백.
