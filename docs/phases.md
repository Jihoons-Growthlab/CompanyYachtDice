# 구현 순서와 완료 조건

0. **INFRA-001 병행** PostgreSQL·Redis Compose와 NestJS 연결·health 검증. docs/tasks/INFRA-001.md 참조.
1. **P0 목업** 시트 전환, 로비→게임, 주사위 보관→기록, 로컬 채팅, 장식 구매·선택을 확인한다. 규칙과 화면을 검토한다.
2. **P1 순수 게임 엔진** `packages/shared`에 카테고리, 점수, 상태 전이 구현. 결정적 주사위 입력으로 경계 테스트와 전체 12라운드 테스트 통과.
3. **P2 방과 멀티플레이** NestJS 및 마이그레이션, 세션, 방, 소켓, 재접속, 기한 처리. 두 브라우저에서 버전·점수·공동 결과 일치.
4. **P3 채팅** 멤버 접근, 중복·속도 제한, 최근 기록과 누락 복구. 같은 메시지 ID의 ACK 유실 재현.
5. **P4 조직과 경제** 소셜 인증과 프로필 등록을 연결한 뒤 가상 회사·부서·직급·칭호·상점 구현. 경합과 롤백을 DB 통합 테스트로 확인.
6. **P5 Unity와 공개 배포** 브리지, 저장과 대체 화면, 배포 환경 및 백업 복원 테스트.

한 단계마다 데모 한 개와 실행 결과를 인수인계에 남긴다. 초기 서비스 목표치는 실측 후 확정한다.
